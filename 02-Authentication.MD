## Authentication ##
Authentication: 
Authentication is a process of verifying or confirming the  identity of a user, device or system by validating the provided credentials before granting access to a network or its resources.

i. It prevents unauthorized usage of systems
ii. It maintains security, reliability, and trust within the system.
iii. It ensures the secure interaction within the network.

## Authentication Methods ##
Authentication will happen in 3types basically.

1. Username and Password-Based Authentication:
-> It is the most commonly used authentication technique
-> each user is assigned a unique username and password
-> During login or authentication the entered password is compared with the stored password. If the credentials match then it grants the access else access will be denied
-> Security depends on the password strength.

2. Physical Identification:(Username and tokens)
-> Uses the physical objects like tokens(RSA, authentication), smart cards and ID cards etc..
-> Combined with passwords or PINs to increase security.

3. Biometric Authentication: (fingerprints, plam, retina, face etc..)
-> It relies on unique biological or behavioral characteristics of individuals
-> removes the needs to remember the password or carry the physical cards
-> Difficult to replicate, provides the higher security.

Common biometric techniques:
Facial, Fingerprint recognition
Retina pattern recognition
Signature verification
Voice recognition


## Types of Authentication ##
Authentication are classified into 3 types. They are
1. Single-Factor Authentication (SFA): SFA relies on one form of verification, typically a username and password. Security is entirely dependent on password strength.

2. Two-Factor Authentication (2FA):2FA requires two different authentication factors to confirm identity. It typically combines something the user knows (password) with something the user has OTP, token, smart card etc..
Even if one factor is compromised, the second factor helps prevent unauthorized access

3. Multi-Factor Authentication (MFA): MFA  uses two or more independent factors for identity verification. It may combine passwords, physical devices, and biometric traits
